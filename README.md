# Innovative-Toy-Design-Using-Modern-Manufacturing-Techniques
Developed an autonomous line-following toy train using Arduino Nano, IR sensors, L293D motor driver, and DC motors. Designed and 3D-printed the chassis using Autodesk Fusion 360. Implemented real-time sensor processing and PWM motor control using Arduino IDE (C/C++), achieving 90–95% line-detection accuracy during testing.
